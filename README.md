# Bank-management-Project 
1. The Bank Management Project is a Python-based web application designed to simulate basic banking operations in a secure and user-friendly manner.
2. The project allows users to create and manage bank accounts digitally through an interactive web interface built using Streamlit. It implements core banking functionalities such as account creation, authentication, deposits, withdrawals, account updates, and account deletion.
3. The backend logic is developed using Object-Oriented Programming (OOPS) principles to ensure modularity, reusability, and data encapsulation.
4. Persistent data storage is handled using JSON-based file handling, acting as a lightweight database. The application enforces validation rules such as age limits, PIN verification, transaction limits, and balance checks to maintain data integrity and security.
5. The project demonstrates a complete CRUD-based banking workflow, integrating backend logic with a modern frontend UI. It is fully deployable on Streamlit Cloud, making it accessible as a live web application
6. Technologies Used
--Python
--Streamlit (Web UI & Deployment)
--JSON (File-based Database)
--OOPS Concepts
--File Handling
--Shallow & Deep Copy
--GitHub + Streamlit Cloud
